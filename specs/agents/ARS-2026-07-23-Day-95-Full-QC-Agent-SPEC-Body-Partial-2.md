### 9.1 Fixture-economy rationale (surfaced)

The unexercised codes are all either **deterministic entry/forensic halts** (`upstream_motion_not_ready`, `upstream_not_success`, `qc_lineage_failure` — single equality/shape assertions, behaviorally trivial, schema-enforced, identical in mechanism to the fleet's proven entry-gate fixtures) or **substance codes whose mechanic is fully covered by a sibling behavioral fixture or the type system**:

- `qc_flag_surface_incomplete` shares TC-04's flag-adjudication machinery — it is the **named optional runbook probe**, chosen precisely to demonstrate the completeness-vs-closure distinction (a MISSING surface / a surface BELOW the minItems-4 floor, versus TC-04's PRESENT-but-OPEN flag) under the one Check-#10 code family.
- `caption_spec_breach` shares TC-03's parity machinery and TC-05's text-scan machinery (a byte-parity break between the burned-in caption and the EDL passthrough, or a multi-line / non-lowercase-sans burn) — it is the second named runbook probe, chosen to demonstrate the escalate-to-Editor path when the deviation is in the EDL source itself.
- `brand_voice_gate_fail` shares TC-01's 11-point adjudication machinery (a single seeded point-fail) and is the third runbook probe, chosen to demonstrate the completeness rule (all 10 other points still evidenced) + the route-to-responsible-authoring-agent path (not reflexively Motion).
- `cost_ledger_overrun` (a `cumulative_usd > combined_envelope_usd`) and `master_unresolved` / `asset_uri_integrity_failure` (an unresolvable `v3_final_uri` / an absolute-URL leak) are single-comparison / single-resolution assertions — schema-negative + the fourth/fifth runbook probes.
- `evidence_hash_break` shares TC-01's tri-anchor-verify machinery (a tampered `motion_spec_evidence_hash` / `audio_spec_evidence_hash` / `edl_evidence_hash`); the broken-anchor-attribution variant (which of the three broke, routing to that agent) is the sixth runbook probe.

**The `qc_reshoot_required` third verdict is the named adversarial runbook probe (not a behavioral fixture).** The `reshoot` verdict is full QC's defining authority (D3), but it is definitionally hard to fixture from outside: it requires the gate to determine that a defect on the finished master is un-fixable in post (unusable Mode-A footage / an unusable Mode-B render surfaced only at the finish). The runbook's adversarial case induces the fail-vs-reshoot judgment slot (§6.4) and asserts the bias-toward-`fail` discipline — a reel where the defect is ambiguously post-fixable-or-not MUST emit `fail` with `detail.reshoot_considered: true`, NOT `reshoot`, because the gate does not spend a production round-trip on a hunch. Spending a behavioral fixture slot on it would displace one of the two PASS-side convergence proofs or the three highest-stakes terminal-original catches (TC-03/04/05) that no other test can provide.

**Slot `qc_agent_failed`** is definitionally un-fixturable from outside (it requires inducing the agent to build a malformed qc report twice); the runbook's adversarial case covers its semantics, including the two forgery variants it catches (an `auto_published: true` claim — a report claiming a publish it never executed, the publish-layer analog of Motion's `motion_processed: true` forgery — and a mode-blind violation where the gate consulted `production_mode` to render its verdict). ## §12 — Verdict Math (LOCKED-as-drafted Day 95)

### 12.1 The ∧-of-gates composition (deterministic PASS/not-PASS split — ONE judgment slot, isolated)

Full QC's verdict math has **two parts, sharply separated**: (1) a **fully deterministic** boolean composition that decides `pass` vs not-`pass` — no thresholds, no weights, no scores — and (2) the **single judgment call in the entire agent**, the `fail`-vs-`reshoot` determination, which fires ONLY when part (1) has already returned not-`pass`. This is the divergence from Motion's §12 (which carried ZERO judgment slots and a two-verdict space): full QC is the terminal **adjudicator**, it restores the third verdict, and it isolates the one judgment surface exactly where QC Pre-flight isolated its own (full QC is QC Pre-flight's terminal twin, D3). The PASS composition itself is as deterministic as any executor's — the judgment lives only in *how a non-pass routes*, never in *whether* the reel passes.

```
PASS = (motion_precondition_met)          # Check 1  — motion verdict == "motion_ready" ∧ output_type == "successMotionSpec"
     ∧ (upstream_success)                  # Check 2  — no errorEnvelope branch consumed
     ∧ (motion_spec_evidence_hash_verified)# Check 3  — SHA-256 recomputes (motion spec not tampered post-finish)
     ∧ (audio_spec_evidence_hash_verified) # Check 3  — SHA-256 recomputes (audio spec not tampered post-finish)
     ∧ (edl_evidence_hash_verified)        # Check 3  — SHA-256 recomputes (EDL not tampered post-conform)
     ∧ (master_resolved)                   # Check 4  — finish_target.v3_final_uri resolves (the finished master exists)
     ∧ (asset_uri_integrity_ok)            # Check 4  — v3_final_uri + every echoed asset_uri stay platform-relative ars://
     ∧ (brand_voice_11_point_all_pass)     # Check 5  — all 11 Brand Voice QC points green (each evidenced)
     ∧ (terminal_firewall_clean)           # Check 6  — 13th-pass hits == 0, RE-DERIVED (∧ consistent with motion_self_check)
     ∧ (format_spec_parity)                # Check 7  — every variant matches the tier promise AND the §8 format spec
     ∧ (caption_spec_parity)               # Check 8  — burned-in captions byte-faithful to the EDL ∧ one-line ∧ lowercase-sans
     ∧ (cost_in_envelope)                  # Check 9  — cumulative_usd ≤ combined_envelope_usd ∧ tier read is correct
     ∧ (flag_surface_closed)               # Check 10 — all 12 agents report ≥4 flags (48+) ∧ every flag resolved
     ∧ (motion_self_check_consistent)      # Check 11 — declared self-check == the gate's independent findings
     ∧ (lineage_intact)                    # Check 12 — well-formed inbound 11-tuple + valid 12-tuple extension
     ∧ (report_construction_valid)         # Check 13 — schema-valid ∧ evidence-hashed ∧ mode-blind ∧ no auto-publish/patch
```

### 12.2 Non-pass routing — the verdict function (THREE outcomes; the one judgment slot)

Any single ∧-term false → the reel is not `pass`, and the verdict function routes per the §6.3 / §3.2 map. **Unlike Motion (which had exactly two outcomes), full QC has THREE** — because the terminal adjudicator can declare a defect un-fixable in post. The routing splits into halts, fails, and the one reshoot determination:

```
# Halts (entry / forensic / construction gates — a fail sub-class that does not route for re-work)
if ¬motion_precondition_met       → halt  upstream_motion_not_ready       (route_back: motion-agent)
if ¬upstream_success              → halt  upstream_not_success            (route_back: motion-agent)
if ¬lineage_intact                → halt  qc_lineage_failure              (forensic — held, no ship verdict)
if ¬report_construction_valid     → halt  qc_agent_failed                 (slot catch-all — 2-strike self-QC)

# Fails (post-fixable substance defects — route to the responsible agent, re-gate after fix)
if ¬motion_spec/audio_spec/edl_hash_verified → fail  evidence_hash_break  (route_back: the broken anchor's agent · forensic)
if ¬master_resolved ∨ ¬asset_uri_integrity_ok → fail master_unresolved | asset_uri_integrity_failure (route_back: motion-agent)
if ¬brand_voice_11_point_all_pass → fail  brand_voice_gate_fail           (route_back: the responsible AUTHORING agent per point)
if ¬terminal_firewall_clean       → fail  qc_firewall_breach              (route_back: motion-agent · escalate editor-agent · forensic)
if ¬format_spec_parity            → fail  format_spec_mismatch            (route_back: motion-agent · editor-agent if duration band)
if ¬caption_spec_parity           → fail  caption_spec_breach             (route_back: motion-agent · escalate editor-agent per source)
if ¬cost_in_envelope              → fail  cost_ledger_overrun             (route_back: production-coord-agent)
if ¬flag_surface_closed           → fail  unresolved_upstream_flag | qc_flag_surface_incomplete (route_back: the named agent(s))

# The ONE judgment slot — evaluated ONLY when a substance defect above is present
RESHOOT_DETERMINATION(defect):
    q = "Can any post-tail agent (Edit Director, Editor, Sound, Motion) fix this
         with the footage and assets that ALREADY EXIST?"
    if q == yes   → keep the fail above, route to that agent
    if q == no    → fail  qc_reshoot_required  →  verdict = "reshoot"  (route_back: production-coord-agent)
    if q == ambiguous → EMIT fail (NOT reshoot); detail.reshoot_considered = true + named rationale
                        # bias-toward-fail: the gate does not spend a production round-trip on a hunch (§6.4)
```

**Precedence:** halts (entry / forensic / construction gates) adjudicate before fails. Among the substance adjudications full QC does **NOT** short-circuit — per the completeness rule (§6.2) it runs ALL substance checks to completion and emits the COMPLETE defect set in one verdict, with the FIRST failing check in §6.2 tier order naming the headline `failure_code` and every other sub-status explicitly dispositioned (no short-circuit nulls). Only a precondition, lineage, or hash break halts further adjudication (the three conditions under which the inputs cannot be trusted and further checks are meaningless). **This is the single behavioral property that distinguishes the terminal adjudicator from every executor before it:** an executor halts on first fail; full QC completes the diagnosis, converting an O(n) round-trip cost into O(1).

**The one route asymmetry worth naming (surfaced):** three codes route to **different agents depending on the defect's source** — `evidence_hash_break` (→ the agent whose anchor broke: motion / sound / editor, per `detail.broken_anchor`), `brand_voice_gate_fail` (→ the responsible authoring agent per failing point, NOT reflexively Motion), and the `qc_firewall_breach` / `caption_spec_breach` / `format_spec_mismatch` finish-vs-source escalation (Motion for a finish-layer defect, Editor if the token/caption/duration originates in the EDL source). The schema author encodes `route_back_to` as a **computed** field, not a per-code const (§16 / §10.4 partial 1), exactly as Motion did for its dual-route `spec_fidelity_breach`.

### 12.3 Properties (why this is the right math for the terminal adjudicator)

1. **The PASS/not-PASS split is fully deterministic** — same inputs, same pass decision, every run, for every ∧-term. There is no soft surface, no gradient in the pass composition. The LLM is adjudicating declared facts + re-deriving one (the firewall count), never scoring. This is the executor-grade determinism posture (Ingest/Editor/Sound/Motion-class), preserved at the terminal gate on the pass side.
2. **The ONE judgment slot is isolated to the non-pass routing** — the `fail`-vs-`reshoot` determination is the single judgment call in the entire agent, and it can NEVER turn a not-`pass` into a `pass` (it only decides *where* a non-pass routes). This is the structural guarantee that the one judgment surface cannot leak into a false pass. It mirrors QC Pre-flight's fail-vs-reshoot slot, intensified: full QC sits at the end where a reshoot is maximally expensive, so the bias toward `fail` is correspondingly stronger.
3. **Monotone on the pass side** — adding a defect can never improve the verdict. There is no compensatory scoring where a clean firewall offsets a format mismatch, or a resolved flag surface offsets a cost overrun. Every ∧-term must be true for `pass`.
4. **Zero-false-pass by construction** — `pass` requires EVERY ∧-term true; ambiguity in the reshoot slot biases to `fail` (never to `pass`). The 0% false-pass target (§8.2) is a **property of the composition**, not a tuned threshold. "WHEN UNCERTAIN, YOU FAIL" is the composition made into a sentence.
5. **Three brand-policy surfaces enforced, not one** — the 11-point voice gate (Check #5), the format/caption spec (Checks #7–#8), and the terminal firewall (Check #6) are three distinct brand surfaces adjudicated in one pass. Motion enforced two (motion behavior + typography); Sound enforced one (loudness); full QC enforces every brand surface the pipeline touches, because it is the terminal gate for all of them.
6. **One field re-derived, the rest adjudicated** — `terminal_firewall_clean` (Check #6) RE-DERIVES `banned_vocab_hits` rather than trusting Motion's declared count; every other ∧-term adjudicates a declared fact + re-verifies a hash. That single asymmetry (§10 field map row 11, partial 1) is deliberate: the entire value of a terminal gate is that it does not trust the upstream self-report on the one check whose failure mode is a brand-safety incident.
7. **Auditable** — the emitted qc report carries the evidence for every ∧-term (§10 per-check evidence rows), so any verdict is recomputable by a human from the qc report alone. Recommend-don't-publish (`human_review_required: true` + `auto_published: false`) depends on exactly this recomputability: the human ratifier can reconstruct the gate's reasoning before approving a publish.

**Divergence from Motion's ∧-with-no-slot (surfaced):** Motion's domain was fully deterministic (a token is in the brand set or it isn't; a lower-third is lowercase-sans or it's an all-caps screamer) — so it carried NEITHER a `revise` nor a `reshoot` branch, a pure two-verdict executor. Full QC's PASS side is equally deterministic, but it is the **adjudicator**, not an executor: it is the only post agent positioned to declare a defect un-fixable in post, so it restores the third verdict Motion/Sound/Editor each dropped. The `reshoot` slot is its defining authority — without it, an unusable-footage defect discovered on the finished master would have no correct route. Full QC is `pass | fail | reshoot`, exactly QC Pre-flight's posture — the judgment slot lives at the two QC gates (the two adjudicators), never at the executors between them.
